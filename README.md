# ACC Coach — первый шаг V1

Небольшой читатель телеметрии ACC без внешних Python-зависимостей.
Пока выводит машину, трассу, скорость, газ, тормоз, передачу и RPM.
Запись CSV, определение кругов и анализ поворотов будут следующими шагами.

## Запуск на игровом Windows-компьютере

Установи Python 3.10 или новее, скопируй `acc_reader.py` и запусти:

```text
py acc_reader.py
```

Можно запустить до игры: программа ждёт Shared Memory ACC.
Запусти ACC и войди в заезд. Остановка — Ctrl+C.
Частота опроса по умолчанию 20 Гц, можно выбрать до 50:

```text
py acc_reader.py --hz 50
```

Названия машины и трассы выводятся как идентификаторы игры.
Статусы меню, паузы и повтора показываются отдельно. При отсутствии обновлений
дольше пяти секунд программа переподключается; длительная пауза также может
вызвать переподключение. Это не запись телеметрии.

## Проверка на Mac без игры

```text
python3 acc_reader.py --demo
```

Демонстрационные показания синтетические. Они проверяют вывод, а не подключение к ACC.

## Как устроен код

`Physics`, `Graphics`, `Static` описывают только начальные части трёх страниц
Shared Memory, необходимые этому шагу. `SharedPage` открывает существующие
страницы Windows только для чтения и освобождает ресурсы при выходе.
`format_telemetry` собирает строку для терминала, `run_live` опрашивает игру.
Страницы читаются независимо: общего атомарного снимка всех трёх страниц нет.

Основа формата: документация Kunos ACC Shared Memory v1.8.12
([копия документа](https://github.com/SolusDev-sys/CppAccSharedMemory/blob/main/ACCSharedMemoryDocumentationV1.8.12.pdf)).
Windows использует UTF-16 и выравнивание структур 4 байта; передача 0 — R,
1 — N, 2 — первая. На реальном Windows-компьютере подключение ещё нужно проверить.

Проверки формата и вывода:

```text
python3 -m unittest discover -s tests
```
