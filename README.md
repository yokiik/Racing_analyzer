# ACC Coach — V1: запись телеметрии

Программа читает Shared Memory ACC на Windows, показывает показания в терминале
и автоматически сохраняет каждый круг в CSV. Внешние библиотеки не нужны.

## Обновление и запуск на Windows

Если скачивал ZIP: останови старую программу, скачай свежий **Code → Download ZIP**
и распакуй. Для работы нужны **оба файла: `acc_reader.py` и `recorder.py`**.
Старую папку `sessions` сохрани, если там уже есть записи.
Если устанавливал через Git, обновление — `git pull` в папке проекта.

С Python 3.10 или новее открой терминал в папке проекта:

```text
py acc_reader.py
```

Можно запустить до ACC. Войди в заезд и проедь несколько кругов. В строке появится
`REC lap 2 (...)`; после пересечения финиша — `Saved lap_02.csv`.
Первый записанный круг намеренно считается неполным: программа не видела его старта.
Для анализа проедь минимум два пересечения финиша после запуска.

Когда закончишь, останови программу **Ctrl+C**, затем открой папку `sessions`
рядом с программой. Каждый новый заезд получает свою подпапку:

```text
sessions/
  2026-10-06_19-30-00_123456_monza/
    session.json
    lap_01.partial.csv
    lap_02.csv
    lap_03.csv
    lap_04.partial.csv
    best_lap.csv
```

Имена `lap_01`, `lap_02` — порядковые номера записанных файлов; номер круга игры
есть внутри CSV и `session.json`. `best_lap.csv` — копия самого быстрого полного
круга, который был валидным во всех наблюдаемых отсчётах и не содержал боксов.
Без подходящих кругов этот файл не создаётся. Невалидные круги тоже сохраняются.

Для разбора пришли папку заезда ZIP-архивом или нужный CSV вместе с `session.json`.

## Что записывается

- Время внутри круга в секундах, номер круга, нормализованная позиция 0–1.
- Скорость в км/ч, газ и тормоз 0–1, руль как исходный канал игры, передача и RPM.
- Топливо, исходные физические каналы TC и ABS, yaw/pitch/roll в радианах.
- Скорости, ускорения, локальная угловая скорость и координаты машины игрока.
- Скольжение, давление шин, температура ядра шин и тормозов по каждому колесу.
- Наблюдаемая валидность, нахождение в боксах, сектор и номера пакетов.

Передачи в CSV: `-1` — задняя, `0` — нейтральная, `1` — первая.
Порядок колёс: `fl`, `fr`, `rl`, `rr`. TC/ABS сохраняются как исходные значения;
программа пока не интерпретирует их как число срабатываний. Пустые координаты
означают, что ID машины игрока не найден в списке активных машин.

## Частота и папка записи

По умолчанию опрос идёт с частотой около 20 Гц; можно выбрать до 50 Гц:

```text
py acc_reader.py --hz 50
py acc_reader.py --output "D:\ACC_sessions"
```

Одинаковые пары пакетов не записываются повторно. Фактическая частота зависит
от игры и компьютера. Данные сбрасываются из буфера примерно раз в секунду.
При нормальном завершении файл закрывается и получает окончательное имя.

## Границы и неполные круги

Финиш определяется по увеличению `completedLaps`; время законченного круга берётся
из `iLastTime`, записывается в `session.json`. Новый круг начинается с первого
доступного отсчёта после финиша. Это дискретная телеметрия: точного отсчёта на самой
линии старта/финиша может не быть.

Пауза не добавляет отсчёты. Повтор, выход из сессии, смена машины/трассы/сессии,
сброс таймера и потеря подключения заканчивают запись неполным файлом.
Пропуск более секунды игрового времени или поздно замеченный старт также помечают
круг неполным. Такие файлы имеют `.partial.csv` и не участвуют в выборе лучшего.
При аварийном закрытии может остаться `.recording.csv`: это доступные исходные
данные незавершённого круга, без гарантии последней секунды и записи в метаданных.

Валидность агрегируется по наблюдаемым отсчётам. Нарушение непосредственно
на финише между отсчётами может быть не замечено. Физика и графика читаются
независимо; общего атомарного снимка страниц нет.

## Деморежим на Mac или Windows

```text
python3 acc_reader.py --demo
```

На Windows можно использовать `py` вместо `python3`. Деморежим записывает
синтетические восьмисекундные круги, с трассой `demo_monza` и `demo: true`
в метаданных. Для проверки полного круга подожди минимум 17 секунд и нажми Ctrl+C.

## Проверка и формат Shared Memory

```text
python3 -m unittest discover -s tests
```

Тесты проверяют бинарные смещения каналов, границы кругов, неполные записи,
паузу, повтор, сброс таймера, выбор лучшего круга и координаты машины игрока.
Первое подключение читателя проверено пользователем на Windows с ACC;
расширенная запись проверена синтетическими тестами, реальный заезд ещё нужен.

Основа формата: Kunos ACC Shared Memory v1.8.12
([копия документа](https://github.com/SolusDev-sys/CppAccSharedMemory/blob/main/ACCSharedMemoryDocumentationV1.8.12.pdf)).
Структуры используют выравнивание 4 байта и Windows UTF-16.
